# ALLAI — Minimal Wardrobe

เว็บไซต์ตัวอย่าง (mockup) ร้านเสื้อผ้าผู้หญิงแนวมินิมอล โทนสีชมพู–ขาว
เขียนด้วย HTML / CSS / JavaScript ล้วน ไม่มีขั้นตอน build และไม่มี dependency ภายนอก

## หน้าเว็บ

| ไฟล์ | รายละเอียด |
| --- | --- |
| `index.html` | หน้าแรก — hero, หมวดหมู่, สินค้าแนะนำ, ลุคบุ๊ค, รีวิว, จดหมายข่าว |
| `shop.html` | หน้าช้อป — ตัวกรองหมวดหมู่/ไซส์/ราคา, ค้นหา, เรียงลำดับ |
| `product.html` | หน้ารายละเอียดสินค้า — แกลเลอรี, เลือกสี/ไซส์/จำนวน, สเปก, ตารางไซส์ |
| `cart.html` | ตะกร้าสินค้า — แก้จำนวน, ลบ, โค้ดส่วนลด, สรุปยอด |
| `about.html` | เกี่ยวกับเรา — เรื่องราว, ความยั่งยืน, ไทม์ไลน์, ทีมงาน |
| `contact.html` | ติดต่อเรา — ข้อมูลติดต่อ, แผนที่, ฟอร์ม, คำถามที่พบบ่อย |

## โครงสร้าง

```
assets/
  css/style.css   — design tokens + ทุกคอมโพเนนต์
  js/data.js      — ข้อมูลสินค้า 16 รายการ + ตัวสร้างภาพ SVG
  js/main.js      — ตะกร้า, wishlist, ตัวกรอง, PDP, ฟอร์ม
```

## ฟีเจอร์

- เมนูหลักพร้อมเมนูย่อย (dropdown) และเมนูมือถือแบบ drawer
- ตะกร้าสินค้าและรายการที่ชอบ เก็บใน `localStorage` (ข้ามหน้าได้)
- ตัวกรองสินค้าแบบเรียลไทม์: หมวดหมู่ ไซส์ ราคา คำค้น และการเรียงลำดับ
- โค้ดส่วนลดตัวอย่าง: `ALLAI10` (ลด 10%)
- ภาพสินค้าทั้งหมดเป็น SVG line-art ที่สร้างจากโค้ด — ไม่ต้องพึ่ง image host
- รองรับจอมือถือ แท็บเล็ต และเดสก์ท็อป

## รันบนเครื่อง

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000

## หมายเหตุ

เป็นเว็บไซต์ตัวอย่างเพื่อการนำเสนอดีไซน์ ยังไม่มีระบบหลังบ้าน —
ปุ่มชำระเงินและแบบฟอร์มทั้งหมดเป็นการจำลองเท่านั้น
